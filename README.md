# ☕ Kiosk Project 

> 간단한 카페 키오스크 시뮬레이션 프로그램입니다. 사용자는 음료와 디저트를 선택하고, 장바구니에 담아 주문할 수 있습니다.

<br>

# 📁 프로젝트 구조
> **Food.java** : ``` Drink,Dessert 를 담을 추상 클래스 ```


<br>


> **Drink.java** : ``` 음료 클래스 ```


<br>


> **Dessert.java** : ``` 디저트 클래스 ```


<br>


> **MainMenu.java** : ``` 메뉴 구성 및 출력 클래스 ```


<br>


> **Kiosk.java** : ``` 사용자 인터페이스 ```


<br>


> **Main.java** : ``` 프로그램 실행 클래스 ```


<br>


# 🧾 주요 기능

<br>

> 메인 메뉴에서 음료/디저트 선택 가능

> 장바구니에 선택 항목 추가

> 추가 선택 여부 확인 및 반복 주문

> 최종 주문 내역과 총 결제 금액 출력

<br>

# ⭐ 실행 예시

<br>

[ MAIN MENU ]
1. Drinks
2. Desserts
0. 종료
<br>

[ DRINKS MENU ]
1. 아메리카노 | W 1500 | 뉴크롭원두와 스페셜티 커피 원두를 블렌딩한 아메리카노
2. 카페라떼 | W 3000 | 진한 에스프레소와 우유가 어우러져 탄생한 부드러운 카페라떼
...
0. 디저트 메뉴로 이동

...

[ 주문하신 내역 ]
- 카페라떼 W | 3000 | 진한 에스프레소와 우유가 어우러져 탄생한 부드러운 카페라떼
총 결제 금액: 3000
감사합니다. 주문이 완료되었습니다!
